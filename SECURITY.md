# Security policy

## Supported versions

PWA UI is currently a pre-release source registry. Security fixes are applied to the latest registry source and documentation deployment; older copied component versions are not updated automatically.

## Reporting a vulnerability

Do not disclose a suspected vulnerability in a public issue. Use the repository's [private vulnerability-reporting form](https://github.com/pnewsam/pwa-ui/security/advisories/new).

Include the affected registry item, reproduction steps, likely impact, browser or framework versions, and any suggested mitigation. Please allow the maintainers time to confirm and coordinate a fix before public disclosure.

## Consumer responsibility

Installed PWA UI components become part of the consuming application. Consumers should review copied source, keep Base UI and application dependencies current, and continue their own dependency, code, and browser security testing.
