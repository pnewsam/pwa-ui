# Support

PWA UI is currently a beta project.

- Use the documentation and browser-support pages for installation and compatibility questions.
- Use [GitHub issues](https://github.com/pnewsam/pwa-ui/issues) for reproducible bugs and focused feature proposals.
- Use the private security-reporting path in [SECURITY.md](./SECURITY.md) for vulnerabilities.

Include the installed item, copied-source changes, framework and browser versions, display mode, and a minimal reproduction when reporting a problem. Support is best-effort until a stable release and support policy are announced.
